# Assets Pipeline

This project uses placeholder assets during MVP development. Keep assets easy to replace and legally clean.

## Rules

- Use only assets with a clear license.
- Prefer CC0, MIT, public-domain, or similarly permissive open-source assets for placeholders.
- Record every external asset source and license under `assets/licenses/`.
- Avoid copyrighted Sevilla imagery, logos, photos, sports marks, brands, and identifiable commercial assets unless explicitly licensed.
- Placeholder shapes generated in Godot scenes are acceptable and can be replaced later by custom sevillano art.

## Current CR-V2 Baseline

- The room hub blockout uses Godot scene primitives (`ColorRect`, `Label`, `Button`) only.
- No external image/audio asset has been imported for CR-V2.

## Alameda Placeholder Slice

- Alameda de Hercules map identity starts with Godot-native primitives only.
- The first slice includes stylized pavement, column props, and fictional red bottle-cap props.
- Bottle-cap props use a fictional `Ci` mark only.
- Do not use the real Cruzcampo name, logo, typography, or other commercial beer branding unless an explicit license is documented.
- See `assets/art/alameda/README.md` and `assets/licenses/alameda_placeholder_assets.md`.
