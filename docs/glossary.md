# Glossary

## Core

The protected base. If enemies reach the end of the path, they damage the core.

## Run

One complete attempt from room start to victory or defeat.

## Round

One defensive cycle: build phase, wave and reward.

## Wave

Enemy sequence inside a round.

## Build phase

Phase where the player places, upgrades or sells defenses.

## Reward

One of three post-round choices that modifies the current run.

## Room interaction

An optional decision in the protagonist room that gives a benefit and sometimes a risk.

## Defense

The game term for tower/trap.

## Pad

A valid build location.

## Tags

String labels used for filtering and synergy.

Examples:

* control
* economy
* armor_break
* wall
* air
* raw_damage
* risk_reward

## Stabilizer

Reward-system rule that prevents a run from dying purely because the player never received a required counter.

## Golden seed

A fixed RNG seed used to detect balance regressions.
