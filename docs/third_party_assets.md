# Third-Party Assets

No third-party assets are currently used.

## Rules

Allowed sources:

* self-made placeholders
* Kenney assets
* OpenGameArt assets only with explicit compatible license
* itch.io assets only with explicit compatible license
* Google Fonts or equivalent with clear license

Every third-party asset must be documented here before commit.

## Asset log format

| Asset | Source | Author | License | File path | Notes |
| ----- | ------ | ------ | ------- | --------- | ----- |

## Placeholder policy

Until gameplay is validated, prefer self-made geometric placeholders.

Do not spend time polishing final art before the MVP loop is playable.
