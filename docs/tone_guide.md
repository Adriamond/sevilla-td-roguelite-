# Tone Guide — Español sevillano/barriero

## Goal

The game should sound local, vulgar, satirical and Sevillian.

It should not sound like neutral Spanish.

The humor should feel like a surreal arcade parody of barrio culture, not like real hatred toward real people.

## Language rules

Player-facing text should be in Spanish with Sevillian/barriero flavor.

Use expressions such as:

- killo
- quillo
- illo
- ompare
- miarma
- en verdá
- yokejé
- susmuerto
- parguela
- tieso
- parné
- la caló
- vaya tela
- no veas
- te via cogé der pescuezo
- te via arrancá er pellejo

Use spelling distortion selectively. It should give flavor but remain readable.

Good density:
- 1 strong slang marker per short UI line.
- 1-3 slang markers per flavor text.
- More aggressive slang only in jokes, taunts, boss lines or defeat/victory screens.

Avoid making every sentence unreadable.

## Examples

Neutral:
"Wave completed."

Sevillian:
"Oleá aguantá, ompare."

Neutral:
"Not enough gold."

Sevillian:
"No te llega er parné, miarma."

Neutral:
"Choose a reward."

Sevillian:
"Elige una movida, killo."

Neutral:
"Enemy reached the base."

Sevillian:
"Se te ha colao uno hasta la cocina, parguela."

Neutral:
"Victory."

Sevillian:
"Sevilla sigue en pie, susmuerto."

Neutral:
"Defeat."

Sevillian:
"Te han dejao el barrio hecho un solar, ompare."

Neutral:
"Increase attack speed."

Sevillian:
"Esto dispara que se las pela."

Neutral:
"Slow nearby enemies."

Sevillian:
"Los deja empanaos perdíos."

## Vulgarity rules

Allowed:

- comic insults
- exaggerated arcade threats
- barrio-style trash talk
- absurd tough-guy lines
- non-realistic cartoon violence

Examples:

- "Te via cogé der pescuezo."
- "Te via arrancá er pellejo."
- "Ven pacá, parguela."
- "Killo, qué haces, alma de cántaro."

Avoid:

- real-world slurs against protected groups
- direct hateful messaging
- realistic threats toward specific real groups
- punching down on poverty, addiction or marginalized communities
- glorifying drug use

## Drug-themed elements

Some elements are arcade symbols, not realistic promotion.

Use abstract wording:

- humo
- colocón visual
- niebla
- turbo
- subidón
- bajona
- pacto
- sangre arcade
- metal
- oro/parné

Do not explain how to consume drugs.
Do not reward real drug use narratively.
Keep it mechanical and cartoonish.

## UI clarity

Gameplay-critical text must remain understandable.

Examples:

Good:
"Ralentiza enemigos un 30% durante 2s. Los deja empanaos."

Bad:
"Er bicho se quea to tieso porque yokejé una fumá que flipas."

Use slang after the mechanical information, not instead of it.

## Safety line

The game mocks archetypes and situations, not real vulnerable people.

If a joke depends purely on humiliating a real marginalized group, rewrite it.
